# XMW 项目集甘特图

基于 `release/22.7-xmw` / 禅道开源版 22.7 的独立扩展，版本 1.0.2。独立实现项目集甘特图的核心使用场景，没有依赖官方收费插件；未声称与官方 2.2 的全部功能逐项一致。

## 安装及权限

本分支已包含全部扩展源码，部署此分支到实际运行目录后即可使用。已有 `extension/custom/program/ext/control/gantt.php` 等同名扩展时，先评估文件冲突。

可直接在 GitHub Release 页面的 Assets 下载 `xmwprogramgantt-1.0.2.zip` 及其 SHA-256 校验文件，也可以生成后台本地安装包：

```bash
python3 scripts/program-gantt/package.py
```

输出 `dist/xmwprogramgantt-1.0.2.zip` 和 SHA-256 文件。版本由本目录 `VERSION` 文件统一声明。备份代码和数据库后，以超级管理员在「后台 → 插件 → 本地安装」上传 ZIP；已有旧版时走后台插件升级。插件不需要 ionCube、额外 PHP 扩展、外部导出服务或数据库结构变更。安装包只包含本插件的明确文件清单，不会带入本地配置或其他定制。

1.0.2 修复通过禅道导航首次进入甘特图为空白的问题：等待页面内容替换完成再初始化，离开页面时清理渲染器。内置「刷新」通过原有查看权限接口局部重新读取数据，不重新加载浏览器或应用框架；等待时保留图表，成功后保留筛选、字段、时间刻度、日期范围、折叠和滚动状态，失败时保留内容并提示。管理员和项目负责人均按同一页面生命周期处理。

1.0.1 修复了安装包最外层目录记录缺失的问题。1.0.0 在后台上传后可能因解压路径错误、无法读取版本声明而提示“不兼容”；取消该次安装，重新上传 1.0.1 即可，无需强制安装。安装包回归测试使用禅道实际的上传/安装解压方法、正常兼容检查和文件复制流程，验证全部 23 个插件文件进入正确目录。

在「后台 → 人员 → 权限」的项目集分类下找到「项目集甘特图」，按用户组分别授予：

| 权限 | 行为 |
| --- | --- |
| 项目集甘特图 (`program-gantt`) | 查看用户本来有权访问的项目集、项目、执行和任务 |
| 编辑甘特图排期 (`program-ganttEdit`) | 允许开启编辑；同时要求对应对象原有的 `program/project/execution/task-edit` 权限 |
| 导出甘特图 (`program-ganttExport`) | 导出前重新校验权限、重新读取数据；不会因具有查看权限而自动获得导出权限 |

普通用户组不会自动获得以上权限；超级管理员按禅道现有规则处理。项目使用「重新定义」权限时，遵循该项目的权限组；受限用户遵循原有对象编辑规则。菜单提供项目集主页入口，页面内可选择一个具体项目集。

XMW Release 同时提供官方镜像的离线部署包和本插件 ZIP。离线镜像未预装插件；部署后从同一 Release 下载插件 ZIP 安装到运行中的 22.7 系统，或部署此分支源码。

## 使用范围和排期规则

- 树形展示项目集、子项目集、项目、执行及父子任务；隐藏的祖先不会泄露名称或 ID。无迭代项目的内部执行隐藏，任务直接归到项目。
- 可选择全部/单个项目集、按项目集状态筛选、按名称搜索、切换天/周/月/季度、显隐执行/任务/日期与负责人/状态/进度、展开折叠及全屏。
- 状态筛选匹配项目集及其下属层级，不是任务状态筛选；搜索保留匹配项的可见祖先。
- 默认只读。勾选「开启编辑」后，拖动条形移动日期，拖动两端修改起止日期；双击条形、按 Enter/空格或使用行内日期按钮可精确输入，也可为未排期项设置日期。
- 拖动后先显示日期确认框，保存只修改当前项。不会级联移动父级、子级或依赖任务。非迭代项目的内部执行继承项目日期。
- 日期采用包含结束当天的自然日，允许单日任务。支持 1900–2099 年；空日期、零日期和远期占位日期显示为未排期，不猜测缺失日期。
- 计划范围必须包含现有子项且位于父级范围内；任务遵循项目 `taskDateLimit` 设置。已完成、已关闭、已取消或冻结对象不可编辑。拒绝越权、GET 修改、无效日期和过期排期，成功更新写入原有操作历史。
- 项目/执行日期更新重新计算已有工作日历；任务使用禅道原有的日期更新及工作流校验。仅传递日期和编辑人字段，不使用完整编辑表单修改关联产品、团队或访问控制。
- 任务进度按已消耗工时占「已消耗+剩余」工时计算，项目和执行使用系统现有进度。不会额外查询隐藏对象来计算新的汇总。

## 导出和性能

PNG 导出当前筛选、字段和展开状态下的完整行集，包括滚动区域外的行。PDF 横向 A3，时间轴与行数分别分页，每页重复列头和时间标记；中文作为本地 Canvas 图像写入 PDF，不需要远程字体或导出接口。PDF 是栅格内容，不提供可选文字。

屏幕行按视口渲染，界面时间范围限制为十年。浏览器仍会获取当前可见范围内的全部节点；这不是服务端分页。PNG 限制为任一边 16384 像素、总计 4000 万像素；PDF 最多 500 页，超出时提示缩小范围或折叠行。服务器和浏览器的实际容量还受数据量与内存影响。

插件使用现代浏览器的 Canvas、Pointer Events、ResizeObserver、Fullscreen 和原生 dialog；建议使用当前 Chrome/Edge/Firefox。

## 验证

```bash
# 无数据库：日历、筛选、层级、PDF 文件结构
node tests/program-gantt/frontend.test.cjs

# 使用 test/config/my.php 的测试数据库；请先初始化 db/zentao.sql
php tests/program-gantt/backend.php

# 构建后使用禅道本身的安装包解析器校验元数据和文件清单
python3 scripts/program-gantt/package.py
php tests/program-gantt/package.php

# 仅在可丢弃的本地应用数据库中运行，测试后必须清理临时样例与账号
GANTT_BROWSER_FIXTURE=1 php tests/program-gantt/browser-fixture.php create
node tests/program-gantt/lifecycle.test.cjs
node tests/program-gantt/browser.test.cjs
GANTT_BROWSER_FIXTURE=1 php tests/program-gantt/browser-fixture.php cleanup
```

浏览器测试需要安装 Playwright 及 Chromium。可通过 `PLAYWRIGHT_MODULE` 指定模块路径、`CHROMIUM_PATH` 指定 Chromium；`GANTT_BASE_URL` 默认 `http://127.0.0.1:8080`，使用 GET 路由的本地应用。`GANTT_ARTIFACTS` 默认 `/tmp/program-gantt-artifacts`，保留桌面/较窄窗口截图、完整 PNG 及多页 PDF。每次重跑浏览器测试前先 cleanup/create，以恢复排期初始值。

卸载使用后台插件管理；直接部署源码的场景则仅移除本插件文件清单中的文件。业务排期和操作历史保留，卸载不会回退已经保存的日期。
